# 还有啥没做

一个 Android 待办与日程应用：把任务、日期、提醒和常用应用入口放在一起，帮助你记下接下来要做的事。

> 当前提供的是 APK 安装包。v2.6.3 已构建，真机安装验收尚未完成；请先自行试用并备份重要数据。

在本仓库下载 [还有啥没做-v2.6.3.apk](./还有啥没做-v2.6.3.apk)，下载后在 Android 设备上打开安装。若系统提示限制，请按提示允许当前来源安装应用。

## 功能

- 按日期查看和管理待办事项，支持单次、每日、每周、每月、法定工作日及 A 股交易日等日期规则。
- 为任务设置时间提醒，并在日历中查看任务和到期日期。
- 为任务关联一个已安装的应用；可从任务入口打开关联应用，并按设置自动完成任务。
- 用自然语言快速填写任务信息；支持设置截止日期及提前到期提醒。
- 可选功能插件包括字体与界面风格等；插件和自动化能力可在应用中按需启用。
- 提供应用内更新检查开关和更新日志。

部分功能依赖 Android 系统权限或厂商后台管理设置。请在应用的设置页面查看状态并按需授权；通知、后台提醒和自动完成可能受到设备省电策略影响。自动完成和提醒相关功能默认关闭，启用前请阅读应用内说明。

## 安装步骤

1. 在 Android 15 或更高版本的设备上下载 APK。
2. 打开下载的 APK；如系统要求，允许浏览器或文件管理器安装未知应用。
3. 按安装器提示完成安装。该应用的显示名称为“还有啥没做”。
4. 首次使用时，根据需要在应用设置中启用提醒、应用使用情况访问等权限。
